# Rezeptbuch

Dieses Projekt ist ein einfaches Rezeptbuch mit einem radialen Suchsystem, das es ermöglicht, Rezepte basierend auf dem ersten Buchstaben des Titels schnell zu finden.

## Funktionen

- **Hinzufügen von Rezepten**: Neue Rezepte können hinzugefügt werden.
- **Bearbeiten von Rezepten**: Bestehende Rezepte können bearbeitet und aktualisiert werden.
- **Löschen von Rezepten**: Rezepte können gelöscht werden.
- **Radiales Suchsystem**: Ein radiales Menü ermöglicht das schnelle Navigieren durch die Rezepte basierend auf dem ersten Buchstaben des Titels.

## Installation

1. Klone das Repository:
   ```sh
   git clone https://github.com/bp173/rezeptbuch.git
   cd rezeptbuch
   ```

2. Installiere die Abhängigkeiten:
   ```sh
   pip install -r requirements.txt
   ```
